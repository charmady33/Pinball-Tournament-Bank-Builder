Pinball Tournament Bank Builder

Build balanced tournament banks from qualifying data, a hand-typed list, or both — mixed era, mixed time, machine-share collisions avoided.

How to use this tool

Loading your games

This tool is built to match the table on matchplay.events: open your tournament there, go to Stats → Arenas, and select the game-by-game table (name, average time, min, max, and play count). Copy it and paste it directly into the box in step 1 — no reformatting needed. Don't have that data, or don't want to use it? Skip step 1 and add games by hand in step 2 instead — pasted and hand-typed games can be mixed freely.

The four steps

1 · Qualifying data (optional): paste your matchplay.events export, or skip straight to step 2.

2 · Review: every game is included by default. Fix any era matches that need it, edit a time estimate by clicking it, or uncheck Active to hold a game out entirely. Add games by hand here too.

3 · Bank settings: choose how many banks and the target games per bank, and how ties should be broken if there are more games than slots (see "Too many games" below). Everything recalculates live.

4 · Banks: review the generated banks, use "Edit banks" to manually swap any game into any slot, then print, copy as text, or download a Word or PDF report.

How balancing works

Balancing: banks are built to keep total play time about even across all of them — the longest games get placed first, then games get swapped between banks to even out the totals — while also spreading machine eras out within each bank rather than clustering them. Two games of the same era are avoided in the same bank whenever there's a choice, and beyond that, farther-apart eras are preferred over adjacent ones — an EM paired with a Modern is favored over an EM paired with an SS, for example.

Too few games: the shortest-average games repeat across two banks so every bank still hits the target size, and each repeat's two rounds are spaced as far apart as possible so the same machine isn't needed by two groups at once.

Too many games: extra games are automatically held out for that run. By default, each era's share of the banks stays about the same as the active pool's, always holding out the longest-average game first within whichever era has to give some up — or switch to the "ignore era" option in step 3 to just hold out the overall longest games instead. You can force a specific held-out game back in ("Include instead" in the Held out this run table); the algorithm automatically holds out a different game to compensate.

Add a game manually

For a machine with no qualifying data — a wildcard, a late addition — enter an estimated time, or use Fast/Medium/Long to fill one from this run's own games (25th/50th/75th percentile). Say whether the estimate is for one player or a full group — a single-player time is multiplied by 4, since every time in the game list is a 4-player estimate. Pick the era too, if you know it, so it doesn't need fixing later.

Game list

Everything's active (included) by default — nothing is left out automatically, even a game with one recorded play. Uncheck Active to hold a game out of the banks. Time is editable — click it to correct an estimate; the Fast/Med/Long tag is colored relative to this run's own games. Era comes from a built-in lookup of ~190 common titles; anything unmatched (homebrews, customs, an ambiguous bare "Star Trek") needs a year or era picked by hand once — it's remembered for next time.
